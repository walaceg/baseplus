# UX - Base+

A experiencia do usuario e um pilar oficial da Base+.

Esta pasta organiza as diretrizes de UX que devem orientar novas aplicacoes, modulos, fluxos, telas e componentes construidos sobre a plataforma.

## Objetivo

Garantir que a Base+ evolua com consistencia visual, clareza de interacao, acessibilidade e previsibilidade operacional.

UX na Base+ nao e apenas aparencia. UX envolve:

- compreensao do contexto;
- clareza de navegacao;
- eficiencia em tarefas recorrentes;
- reducao de erro;
- feedback adequado;
- acessibilidade;
- consistencia entre modulos.

## Principio

Toda interface deve ajudar o usuario a trabalhar melhor.

A Base+ prioriza interfaces claras, discretas, consistentes e adequadas a sistemas corporativos.

## UX como Pilar Oficial

UX passa a ser oficialmente um dos pilares da Base+, juntamente com Arquitetura, Engenharia, Operacoes e Qualidade.

Toda nova funcionalidade deve ser concebida considerando simultaneamente:

- Arquitetura;
- Engenharia;
- UX;
- Qualidade;
- IA.

Somente depois disso um prompt de implementacao deve ser gerado.

## Integracao com a Engenharia Base+

UX se integra aos demais artefatos oficiais da plataforma:

- `VISION.md`: define o proposito institucional da Base+.
- `engineering/architecture/principles.md`: define os principios permanentes.
- `engineering/architecture/decisions.md`: registra decisoes arquiteturais.
- `engineering/quality/quality-gates.md`: inclui o Gate UX.
- `engineering/playbooks/README.md`: conduz conversas antes de prompts.
- `engineering/playbooks/100-ai-collaboration-method.md`: conecta humanos, IA e Codex.
- `engineering/release/release-process.md`: consolida validacoes antes da release.

## Como utilizar

Use estes documentos antes de implementar:

- nova aplicacao;
- novo modulo;
- nova funcionalidade;
- revisao de tela;
- ajuste visual;
- revisao de elegancia;
- fluxo de formulario;
- listagem ou tabela;
- mudanca de navegacao;
- release com impacto visual.
