# Checklist de Qualidade de UX

Use este checklist antes de concluir uma tela, modulo ou release.

## Clareza

- [ ] O objetivo da tela e compreensivel.
- [ ] A acao principal esta clara.
- [ ] Textos sao objetivos.
- [ ] Termos seguem o dominio do usuario.

## Consistencia

- [ ] Componentes seguem os padroes da Base+.
- [ ] Cores usam tokens.
- [ ] Espacamentos e hierarquia visual sao consistentes.
- [ ] Acoes seguem o mesmo comportamento de outros modulos.

## Interacao

- [ ] Ha feedback para carregamento.
- [ ] Ha feedback para sucesso.
- [ ] Ha feedback para erro.
- [ ] Acoes destrutivas exigem confirmacao.
- [ ] Estados vazios orientam o usuario.

## Formularios

- [ ] Campos possuem rotulos.
- [ ] Validacoes sao claras.
- [ ] Dados sao preservados em erro quando possivel.
- [ ] Formularios longos estao organizados em secoes.

## Tabelas

- [ ] Colunas sao relevantes.
- [ ] Filtros sao claros.
- [ ] Acoes por linha sao previsiveis.
- [ ] Responsividade preserva dados essenciais.

## Acessibilidade

- [ ] Contraste adequado.
- [ ] Foco visivel.
- [ ] Navegacao por teclado considerada.
- [ ] Imagens funcionais possuem texto alternativo.
- [ ] Estados nao dependem apenas de cor.

## Operacao

- [ ] A tela lida com erro de API.
- [ ] A tela lida com permissao insuficiente.
- [ ] A tela lida com dados vazios.
- [ ] A tela lida com carregamento lento.

## Checklist minimo oficial

- [ ] Heuristicas de Nielsen.
- [ ] Consistencia.
- [ ] Elegancia.
- [ ] Simplicidade.
- [ ] Feedback.
- [ ] Estados vazios.
- [ ] Loading.
- [ ] Responsividade.
- [ ] Tipografia.
- [ ] Espacamento.
- [ ] Icones.
- [ ] Mensagens.
- [ ] Acessibilidade.
- [ ] Performance percebida.
- [ ] Fluxo intuitivo.

## Manifesto Base+

- [ ] A interface possui pouco ruido.
- [ ] A hierarquia esta clara.
- [ ] A tela respira.
- [ ] O foco da tarefa esta evidente.
- [ ] O sistema parece leve mesmo sendo poderoso.
