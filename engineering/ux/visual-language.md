# Linguagem Visual

## Objetivo

Definir a direcao visual da Base+ para interfaces corporativas.

## Identidade

A Base+ deve usar uma linguagem visual:

- limpa;
- discreta;
- profissional;
- consistente;
- orientada a trabalho;
- adaptavel por branding.

## Tokens

Cores, espacamentos, bordas, sombras e tipografia devem ser definidos por design tokens e CSS Variables.

Nao usar cores fixas em componentes de produto.

## Cores

Cores devem comunicar hierarquia, estado e acao.

Use cores de marca para elementos principais, mas preserve contraste e legibilidade.

## Tipografia

Texto deve favorecer leitura rapida.

Titulos devem ser proporcionais ao contexto. Paineis, cards e tabelas nao devem usar escala de hero.

## Bordas e Sombras

Use bordas e sombras com moderacao.

Profundidade deve ajudar a distinguir camadas, nao decorar a tela.

## Iconografia

Icones devem reforcar a acao.

Evite icones ambiguos sem tooltip ou texto complementar quando a acao nao for evidente.

## Responsividade

Interfaces devem funcionar em desktop e telas menores sem sobreposicao, truncamento critico ou perda de acao essencial.

## Tipografia

Tipografia deve favorecer leitura rapida, hierarquia e confianca.

Titulos devem ser proporcionais ao contexto. Paineis, cards e tabelas nao devem usar escala de hero.

## Hierarquia

A tela deve guiar o olhar do usuario entre titulo, contexto, conteudo, acoes e feedback.

## Espacamento e Grid

Espacamento cria respiro visual.

Grid cria alinhamento, consistencia e previsibilidade.

## Cards

Cards devem representar unidades reais de informacao ou acao.

Evite cards decorativos ou cards dentro de cards.

## Design Tokens e CSS Variables

Todo componente deve utilizar Design Tokens e CSS Variables.

Nunca utilizar cores fixas.

Tokens devem controlar:

- cor;
- fundo;
- borda;
- texto;
- sombra;
- raio;
- espacamento;
- foco;
- estados.

## Conceitos visuais

Respiro visual: capacidade da interface de organizar informacao sem sufocar o usuario.

Equilibrio: distribuicao adequada entre informacao, acao e feedback.

Minimalismo: mostrar apenas o que ajuda a tarefa.

Elegancia: clareza, proporcao, consistencia, discricao e utilidade.
